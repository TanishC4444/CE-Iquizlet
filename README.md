# CE-I Quizlet Generator

A small Python utility that transforms study material into Quizlet-style study data and a browser-ready output.

## Contents

- `test.py` — generation script
- `input.txt` — source study material
- `quiz_output.json` — generated structured study data
- `quiz_output.js` and `index.html` — browser-facing output

## Usage

```bash
python test.py
```

Update `input.txt` with the material to convert, then open `index.html` in a browser to view the result.

## Notes

This is an educational utility. Keep generated outputs small and remove any private or copyrighted study material before publishing it.
